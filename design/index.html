Pairing rules

  • Fraunces for page-level headings (Display, H1, H2) and brand hero text
  • Inter for everything else — H3 and below, body, labels, buttons, nav, captions
  • Never use a third font. These two cover all needs.

06 — Guidance

Do's and don'ts

Keep Langy feeling warm, approachable, and consistent across every touchpoint.

Do

Use the flashcard shape consistently

The 96:62 rounded rectangle is the brand's core geometric motif.

  • Keep the 1.55:1 aspect ratio on all flashcard shapes
  • Use ~12% border-radius relative to width
  • Scatter subtle flashcard shapes as decoration
Don't

Distort the flashcard proportions

Stretching or squishing breaks the brand's geometric identity.

  • Never change the mascot's aspect ratio
  • Don't use squares or circles as substitutes
  • Avoid sharp-cornered rectangles for flashcards
Do

Use warm, rounded shapes

Rounded corners (12–24px) make the UI feel friendly.

  • Use rounded-card (12px) or rounded-section (24px)
  • Prefer pill-shaped buttons and badges
  • Stay consistent — don't mix sharp and rounded
Don't

Use sharp corners or harsh edges

Sharp rectangles feel clinical and unfriendly.

  • Avoid 0px border-radius on interactive elements
  • Skip harsh 1px solid borders on containers
  • Don't use hard drop shadows
Do

Keep the palette warm

Cream backgrounds and blue accents create a calm learning space.

  • Use cream-light (#FFFAF5) as page background
  • Apply primary blue sparingly as accent
  • Use hierarchy via weight and color, not just size
Don't

Use cold grays or pure white/black

Our palette has warm undertones throughout.

  • Avoid #000 for text — use Ink (#2D2926)
  • Avoid pure #FFF — use Cream Light
  • Skip cool gray tones (use warm neutrals)
Do

Use lines everywhere

All shapes across the app — cards, containers, buttons, decorative elements — should have a subtle quality. Use slightly wobbly bezier paths or SVG filters instead of perfect CSS rectangles. This makes the entire experience feel cozy, approachable, and crafted by hand.

  • Use SVG paths with slight wobble for card outlines and containers
  • Break straight edges into gentle curves — no perfectly straight lines
  • Keep the imperfection subtle — it should feel warm, not sloppy
Don't

Use perfectly geometric shapes

Perfect CSS border-radius rectangles feel sterile and generic. They lack the warmth that defines Langy.

  • Don't rely on pure CSS rounded rects for key UI elements
  • Avoid perfectly circular or elliptical shapes
  • Don't make the wobble so strong it looks broken or unintentional
Do

Give the mascot personality

The flashcard friend is our brand ambassador.

  • Use at comfortable sizes (36px width+)
  • Keep the path style — it's intentional
  • Add subtle float/bounce animations in hero areas
Don't

Write formal or punishing copy

Never make users feel bad about missed sessions or wrong answers.

  • Avoid "You failed" — say "Almost! Try again"
  • Skip corporate jargon and stiff phrasing
  • Don't guilt-trip about streaks or missed days

Implementing the effect

To achieve the look, use randomized CSS border-radius with the 8-value slash syntax. Each element gets a unique wobbly shape on render. See useHandDrawn.ts in the frontend for the React hook. The formula: border-radius: rand(180,255)px rand(10,25)px rand(180,240)px rand(10,25)px / rand(10,25)px rand(180,240)px rand(10,25)px rand(180,255)px. Pair with a subtle 2px solid border in a warm neutral. Apply to cards, buttons, inputs, and decorative shapes.
